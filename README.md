# HabitFlow

A habit tracker built with Flutter (web). Track daily, weekly and monthly habits, see streaks,
a monthly heatmap and 30-day statistics. Data is stored locally with `shared_preferences`.

**Features:** progress ring, animated check-offs, add/edit/delete habits (category, colour,
frequency), monthly heatmap, stats and milestones, light/dark/system theme, backup and restore.

**Tech:** Flutter, Dart, Material 3, CustomPainter, shared_preferences, GitHub Actions + GitHub Pages.

Live demo: see the link in the repository's "About" section.
